# 🌉 SkillBridge — Student Career & Skill Development Platform

> **"Build Skills. Prove Your Worth. Launch Your Career."**

SkillBridge is an end-to-end career acceleration and portfolio management platform designed for computer science students and early-career software engineers. It replaces fragmented spreadsheets and ad-hoc tutorial bookmarking with a structured, data-driven methodology that bridges academic study with industry hiring standards.

### 🌟 Core Capabilities
- 🎯 **Career Skill Gap Analyzer**: Automated matrix comparing candidate competencies against 5 industry profiles (*Full Stack*, *Frontend*, *Java Backend*, *Data Analyst*, *QA/Testing*) with 1-click sprint recommendations.
- 📊 **Career Readiness Score (0–100)**: Mathematically weighted algorithm combining Target Skills (40%), Portfolio Completeness (25%), Technical MCQs (20%), and Roadmap Execution (15%).
- ⏱️ **Technical Assessment Center**: 35-question timed MCQ engine with question palettes, automatic submission, scoring, and detailed concept explanations.
- 💼 **Internship Explorer & Kanban Pipeline**: Curated opportunity listings with stipend details, work modes, bookmarking, and a full recruitment pipeline (*Saved*, *Applied*, *Interview*, *Offered*, *Archived*).
- 📁 **Project Portfolio Manager**: Full CRUD for student repositories with live demo links and a recruiter-ready Public Portfolio preview modal.
- 🗺️ **Personal Learning Roadmap**: Task planner with daily streak tracking 🔥, weekly goals progress bars, and gap recommendations.
- 🌓 **Dual Themes & Offline Backup**: Dark Charcoal & Clean Light modes with JSON backup export, import validation, and factory reset for live demos.
